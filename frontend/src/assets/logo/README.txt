AskPDF logo export

askpdf-logo-*   Mark + wordmark, transparent background
  light-mode = for light backgrounds, dark-mode = for dark backgrounds
askpdf-mark-*   Symbol only, transparent background
favicon-*       App-icon style tiles (rounded square), served from frontend/public/
  favicon-light-mode = teal tile, shown when browser/OS is in light mode
  favicon-dark-mode  = lime tile, shown in dark mode

HTML:
<link rel="icon" href="favicon-light-mode.svg" media="(prefers-color-scheme: light)">
<link rel="icon" href="favicon-dark-mode.svg" media="(prefers-color-scheme: dark)">

Colours: Deep Teal #00272C · Lime #E1FF51 · Off-white #F2F2F2
